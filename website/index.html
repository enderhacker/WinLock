WinLock - Pantalla protegida

Superficie secundaria oscurecida para evitar lecturas indiscretas y ocultar el cursor.

Modo pasivo activado

Qué hace exactamente WinLock

Anti-Suspensión Activo

Llama a las APIs del núcleo de Windows (SetThreadExecutionState) para evitar que el ordenador entre en suspensión o apague los discos.

Multimonitor Real

Enumera cada pantalla conectada mediante la API de Win32. Bloquea monitores secundarios con pantallas protectoras independientes respetando el escalado DPI.

Bloqueo de Atajos y Cursor

Atrapa y oculta el cursor del ratón, y un hilo vigilante impide abrir herramientas como el Administrador de tareas, CMD, PowerShell o combinaciones de teclas.

Portabilidad y Limpieza

No requiere instalación, no agrega servicios al inicio ni modifica el registro del sistema. Incluye comprobación y descarga automática de actualizaciones.

Instrucciones de uso

Paso 01

Abre el ejecutable

Descarga el archivo WinLock.exe y ejecútalo. No requiere instalación previa.

Paso 02

Configura la clave temporal

Introduce la contraseña que usarás para desbloquear y, si lo deseas, añade una nota informativa para tus compañeros.

Paso 03

Desbloquea al volver

Cuando regreses, teclea directamente tu contraseña y pulsa Enter. El explorador y el cursor se restaurarán al instante.
